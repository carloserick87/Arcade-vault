## Project

Arcade Vault: online gaming platform where players compete for the highest score. Currently a fresh Create Next App scaffold — no game, auth, or data layer exists yet.

Workflow is Spec Driven Design via the `/spec` and `/spec-impl` skills from https://github.com/Klerith/fernando-skills (install: `npx skills@latest add Klerith/fernando-skills`). Write/consult a spec before implementing features.

## Commands

- `npm run dev` — dev server (also regenerates the AGENTS.md block; leave it in place)
- `npm run build` — production build (also type-checks)
- `npm run lint` — ESLint 9 flat config (`eslint.config.mjs`, next core-web-vitals + typescript)
- No test runner configured yet.

## Stack / conventions

- Next.js 16 App Router (`app/`), React 19, TypeScript strict. Next 16 APIs differ from older versions — check `node_modules/next/dist/docs/01-app/` before using routing, data fetching, caching, or config APIs.
- Typed route helpers like `LayoutProps<"/">` / `PageProps` are global types generated by Next (see `app/layout.tsx`); no import needed.
- Tailwind CSS v4 via `@tailwindcss/postcss`: no `tailwind.config.*`; theme tokens are declared in `app/globals.css` with `@theme inline` and CSS variables (light/dark via `prefers-color-scheme`).
- Fonts: Geist / Geist Mono via `next/font/google`, exposed as `--font-geist-sans` / `--font-geist-mono`.
- Path alias `@/*` → repo root.
